# Growth System Workstream Plans

Last updated: 2026-08-13 12:43:56 PDT — edited by: Codex

This directory holds decision-complete implementation detail for one subsystem.
It does not track global status; detailed execution state belongs in
`planning/GROWTH-SYSTEM-MASTER-CHECKLIST.md`, while the synchronized
`planning/GROWTH-SYSTEM-ORDERED-TASK-MAP.md` is the founder-facing roadmap.

Each plan states outcome, dependencies, boundaries, interfaces, tasks, tests,
failure behavior, deployment/rollback, completion evidence, and decisions that
still belong to Mark. The operating loop is: select the next ready checklist
item; refresh its plan; reconcile contracts; create a bounded agent task card;
execute in the correct app repository; test; record evidence in the master.

Supporting artifacts may be workstream plans, interface contracts, agent task
cards, test plans, runbooks, decision briefs, and weekly views.
