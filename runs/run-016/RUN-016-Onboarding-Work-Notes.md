# [[runs/run-016/RUN-016-Reflective-Onboarding|RUN-016]] — Onboarding Work Notes

## Frozen founder concept

- A guided reflection should give value in each prompt, not feel like a survey.
- The reflection forms a web-based personal page and an initial experience.
- The member selects one current focus; explicit choices and reactions can
  shape later suggestions.
- “Texting program” is not suitable customer-facing language.

## Retained choices

1. Working experience name: **Your MindfulText Rhythm**.
2. Member language: **current focus**, not a clinical or performance “goal.”
3. V0 uses deterministic, explainable preference mapping—not open-ended AI
   profiling or sensitive-data personalization.
4. The reflection is the value exchange; the personal page and first practice
   are the activation surface.
