# [[runs/run-017/RUN-017-Social-Search-Route|RUN-017]] — Social/Search Route Qualification Report

Last updated: 2026-07-21 13:16:27 PDT — edited by: Codex

## Result

**Concept qualified; external baseline not authorized.** The viable route is
one transparently MindfulText-owned character account distributing one useful,
claim-bounded founder asset. It is not a covert employee-account strategy, a
generic satire channel, or a promise to rank for broad mindfulness terms.

## What changed

- **Search focus narrowed:** Generic mindfulness/comedy and mindfulness-text
  query space does not justify an organic-ranking bet. The candidate asset is
  the existing CCBHC-adjacent staff-support boundary article/checklist route.
- **Employee boundary made explicit:** An employee may operate a branded
  character only with voluntary internal terms and clear post-level affiliation
  disclosure. A profile-only disclosure is insufficient for endorsements.
- **Success stack staged:** Relevant attention, search discovery, and
  commercial learning are a sequence. Only the measurement specification exists
  today; no signal has been collected.
- **Satire constrained:** The target is the bad incentive or self-defeating
  workplace pattern—not people, patients, care workers, or structural hardship.

## Evidence and uncertainty

MindfulText's current public voice and [[runs/run-014/RUN-014-CCBHC-Site-Strategy|RUN-014]]'s draft CCBHC strategy make the
asset direction coherent. FTC and Google guidance make transparent authorship,
post-level relationship disclosure, and people-first content non-negotiable.
The public query check is directional only: it cannot establish ranking
difficulty, volume, demand, or expected conversion. See [source ledger](SOURCES.md).

## Next decision

Mark may separately approve one manual social baseline after naming: platform,
asset URL, character/account identity, disclosure language, voluntary operator,
post/time ceiling, target audience, and manual review rubric. This run does not
authorize any of those external actions.
