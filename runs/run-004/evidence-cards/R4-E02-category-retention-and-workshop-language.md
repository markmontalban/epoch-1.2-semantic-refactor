# R4-E02 — Retention-program and workshop language

Last updated: 2026-07-14 01:34:32 PDT — edited by: Codex

**Sources:** California HCAI, [Medi-Cal Behavioral Health Recruitment and
Retention Program](https://hcai.ca.gov/workforce/initiatives/behavioral-health-bh-connect/mbhrrp/)
(official government page, opened 2026-07-14); Calm Health,
[Calm Workshops](https://health.calm.com/calm-workshops/) (commercial page,
opened 2026-07-14).

**Observed facts:** HCAI describes a behavioral-health program using
recruitment and retention bonuses, supervision support, and
certification/licensure assistance. Calm describes tailored interactive virtual
work sessions using the phrases resilience, connection, and mental wellness.

**CDP facet:** category and language. **Limit:** A public policy program and a
seller's positioning page do not establish a community-provider's priorities,
buyer path, or outcome from a daily text benefit.
