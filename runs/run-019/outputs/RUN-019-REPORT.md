# [[runs/run-019/RUN-019-Pulse-Public-Asset-Audit|RUN-019]] — Report

Last updated: 2026-07-28 10:44:41 PDT — edited by: Codex

## Outcome

Pulse is a promising private prototype and possible future insight source, but
it is **not qualified as a public evidence asset**. The retained code supports
the existence of a system designed to ingest and analyze healthcare-community
material; it does not establish the corpus's current state, a defensible public
count, user-content permissions, or reproducible methods.

The only inspected count is an internal June 2025 note: 5,311 total records,
with a 965-post recent-week subset and a 963-post search index. The founder's
10K/40K recollection remains unverified. No public count should be used.

## Recommended disposition

- **Keep:** the source code and workflow exports as a private technical asset.
- **Do not use publicly:** source text, quotes, usernames, links, sentiment
  outputs, trend claims, or searchable records.
- **Do not reactivate:** the workflow, app, API, or connected data sources.
- **Next required evidence:** a separately approved, read-only, local-only
  provenance inventory as specified in
  [[runs/run-019/outputs/PULSE-PUBLIC-ASSET-QUALIFICATION|the qualification]].

The current Reddit terms further support this conservative posture: they limit
user-content use to the permitted use case, prescribe retention/deletion
conditions, and state that commercial or certain research/API uses require a
separate agreement. That is a policy cue, not legal advice; it should be
reviewed against the actual historical source arrangement before any public or
commercial decision.

## What this enables now

It gives the Social Studio a clean rule: Pulse may inspire a private question,
but it cannot be cited as a public insight or converted into content until its
provenance passes review. Mark can still make founder-led stories about systems,
care, attention, and agency without turning an unqualified dataset into proof.
