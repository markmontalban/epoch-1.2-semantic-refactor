## MindfulText Growth authority

For current MindfulText Growth work, first read the founder-facing
[[planning/GROWTH-SYSTEM-ORDERED-TASK-MAP|Growth System Ordered Task Map]],
then the detailed [[planning/GROWTH-SYSTEM-MASTER-CHECKLIST|Growth System
Master Checklist]], then the applicable dated `DR-*` record in `decisions/`.
The Ordered Task Map is the roadmap, the Master Checklist is the execution
authority, and dated decisions own approvals. The repository-root Epoch 1
entry, status, and handoff notes remain historical research/run records unless
they explicitly link to this current Growth authority.

For documentation changes, preserve historical snapshots and point readers to
the highest relevant canonical owner (subject, run, roadmap, checklist, or
dated decision) when a direct reference is useful. Navigation views do not
replace those records or create a separate completion requirement.

# Rule

Agents should exhaust safe, authorized, agent-doable work before assigning a
task to Mark. This includes routine browser and network observations, tests,
diagnostics, evidence collection, status reconciliation, repository lookup,
and safe fallback approaches when the first tool or environment is blocked.

Ask Mark only for a consequential product decision, explicit approval,
credentials or account access only he can provide, an irreversible action, or
a genuine external blocker after reasonable agent-accessible paths have been
exhausted. When Mark must act, provide literal minimal steps and take the work
back immediately afterward.

## Prototype tempo

Mark is a seed-to-series-A founder. Use the smallest loop that proves the next
real step. Do not run a large-company staging program when nothing is live and
no records need to be kept yet.

Keep these distinctions:

- Laptop, throwaway test data, private-test URL, and live are different proofs.
  Passing one does not upgrade the others.
- Do not copy test records into live. First live use starts from empty live
  settings and a checked snapshot, not a clone of the test environment.
- Live put-online, public collection, and outreach stay behind a dated
  decision.

Avoid isolation theater:

- Prefer resetting throwaway test data over multi-environment diagnosis.
- Do not assign Mark hosting-console work, secret-file homework, or rebuild
  click-paths unless only he can provide a value and agent paths are
  exhausted — then name that one action and take the work back.
- Do not expand an acceptance walk into a large QA script before the basic
  path works.
- Do not switch to live “to go faster” when that only adds a second setup.
- Do not open parallel reviewer loops for the same blocker.
