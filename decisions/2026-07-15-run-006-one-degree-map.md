## DR-34 — [[runs/run-006/RUN-006-One-Degree-Market-Map|RUN-006]] one-degree care-delivery market map

**Decision:** Mark approved and Codex executed `RUN-006`, an initial,
public-research-only lab-validation run for `SEG-001 — Care-delivery
organizations`. The run maps up to 50 direct relationship nodes under, beside,
or above the center segment, including segments, ecosystem organizations,
representative provider organizations, funders, regulators, payment structures,
quality bodies, workforce systems, and infrastructure.

**Scope amendment:** [[runs/run-006/RUN-006-One-Degree-Market-Map|RUN-006]] is a new run in the existing Epoch 1 sequence. It
does not create a code fork, merge code, or create a second data system. Its
complete map and source ledger live together under `runs/run-006/outputs/`.
The six named provider organizations retained from [[runs/run-005/RUN-005-Organization-Registry|RUN-005]] are comparison
examples, not duplicate account-registry records or outreach leads.

**Research boundary:** Public official organization, government, sector-body,
professional-association, accreditation, and public program sources only. No
logins, private data, personal contact information, scraping, monitoring,
outreach, CRM writes, publishing, paid provider, local-model worker, or
external spend. Public evidence establishes relationships and operating
context; it does not establish buyer authority, budget, willingness to pay,
efficacy, current unmet need, or permission to contact.

**Result:** The run passed. It retained 50 nodes with explicit `center`,
`under`, `beside`, and `above` relationships, node types, source references,
priority tiers, and unknowns. The strongest next comparison is
`SEG-003 — FQHCs with integrated behavioral health`; `SEG-002 / CCBHCs` remains
the lead branch. Home health, hospice, and aging services remain separate
adjacent hypotheses rather than being merged into `SEG-001`.

**Status:** Mark-approved and completed 2026-07-15. Extends `DR-31` and
`DR-33`; preserves `DR-29` no-outbound and source-boundary controls.
