## Signal types

- **Pain:** repeated or specific evidence that the problem matters.
- **Resonance:** a relevant reaction, reply, or useful objection.
- **Intent:** a request for a call, demo, pricing, or pilot discussion.
- **Commitment:** a pilot, payment, LOI, or equivalent real commitment.
- **Contradiction:** evidence that weakens a path or assumption.

## Collection modes

- **Now — manual:** paste a concise observation from a conversation, research,
  pilot, Reddit workflow, or outbound result into the table.
- **Next — source workflow:** when one source repeats, create a small template
  workflow that produces the same row shape. For example, a Reddit collector
  can turn a selected post/comment into a `Pain` or `Resonance` record.
- **Later — connector:** if an email campaign or another system reliably
  produces valuable signals, either import a manual export or connect it to
  write this same row shape. Decide that only when the source is active and
  worth maintaining.
