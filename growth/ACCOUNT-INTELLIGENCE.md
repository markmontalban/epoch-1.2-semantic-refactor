# Growth — Account Intelligence

Last updated: 2026-07-13 21:47:28 PDT — edited by: Codex

This is a public-research workspace for named organizations once a qualifying
hypothesis enters a bounded research run. It is not a CRM, contact list,
automated monitor, or outreach queue. Each entry must link public sources and
state what it changes in a hypothesis; public visibility never proves buying
intent. [DR-29](../decisions/2026-07-13-segment-linked-runs.md)

## Account-card fields

| Field | Use |
| --- | --- |
| `account_id` | Stable `ACC-###` identifier; use the next unused number. |
| `segment_id` / `icp_id` | Most specific market and buyer context. |
| Public evidence | Dated URL and concise fact only. |
| Buyer roles | Public roles or functions, never private contact details. |
| Market language | Repeated public terms, claimed priorities, and category framing. |
| Research priority | 0–8: segment/workflow fit, public pain/trigger, buying-group visibility, and strategic relevance—each 0–2. |
| Next research question | What public research or later authorized conversation must resolve. |

## Operating rules

- A public post, leadership share, job listing, strategy page, or competitor
  page can inform context, terminology, and a research question. It cannot
  establish readiness, budget, or willingness to pay.
- Record an account only during an approved bounded run. Revisit sources only
  through a later manual research run; no scraping or continuous monitoring.
- Record buyer roles as functions (for example, workforce, clinical,
  operations, quality, or procurement), not personal dossiers.
- Candidate accounts from Run 002 will appear below with citations and a
  `last_checked` date.
