# Modular Sales Playbooks

Canonical playbook guidance composes in this order:

1. [[playbooks/PLAYBOOK-CORE|Shared core]]
2. Segment overlay
3. ICP or buyer-role overlay
4. Learning-thread overlay
5. Optional account-specific evidence module

An overlay records only what differs. The complete playbooks retained under
[[runs/run-013/RUN-013-Sales-Playbooks|RUN-013]] remain historical outputs and
are not replaced by this modular layer.
